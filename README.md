# LINE News Assistant

AI ผู้ช่วยรายงานข่าว/ค้นข้อมูล ใช้งานผ่าน LINE ได้ทั้งแชทส่วนตัวและกลุ่ม
รองรับ: ค้นข่าวสด, ราคาหุ้น, ติดตามหัวข้อแล้วรายงานให้ทุกวันอัตโนมัติ

---

## ภาพรวมสิ่งที่ต้องมี

1. บัญชี LINE Official Account + Messaging API channel (ฟรี)
2. เซิร์ฟเวอร์ที่รันโค้ดนี้อยู่ตลอด พร้อม URL แบบ https (แนะนำ Render.com free tier)
3. Anthropic API key (สำหรับให้ Claude ช่วยสรุปข่าว)

---

## ขั้นตอนที่ 1: สร้าง LINE Messaging API Channel

⚠️ **หมายเหตุ:** ตั้งแต่ 4 กันยายน 2024 เป็นต้นมา LINE **ไม่ให้สร้าง Messaging API channel ตรง ๆ จาก Developers Console แล้ว**
ต้องสร้าง LINE Official Account ผ่าน LINE Official Account Manager ก่อน แล้วค่อยเปิดใช้ Messaging API จากตรงนั้น
(อ้างอิง: [ประกาศจาก LINE Developers](https://developers.line.biz/en/news/2024/09/04/no-longer-possible-to-create-messaging-api-channels-from-console/))

ขั้นตอนที่ถูกต้องตอนนี้:

1. เข้า https://www.linebiz.com/th/entry/ (หรือ https://manager.line.biz) แล้วล็อกอิน/สมัคร **LINE Business ID** ด้วยบัญชี LINE หรืออีเมล
2. กรอกฟอร์มสร้าง **LINE Official Account** ใหม่ (ตั้งชื่อบอท, เลือกประเทศ Thailand, หมวดหมู่ ฯลฯ) แล้วยืนยัน
3. เมื่อสร้าง Official Account เสร็จ ให้ล็อกอินเข้า **LINE Official Account Manager** (https://manager.line.biz) → เลือกบัญชีที่สร้าง
4. ไปที่เมนู **Settings (ตั้งค่า) > Messaging API** → กด **Enable Messaging API** (เปิดใช้งาน Messaging API)
   - ระบบจะให้เลือก **Provider** — เลือก Provider เดิมถ้ามี หรือสร้างใหม่ตั้งชื่อบริษัท/ทีมของคุณ
   - กด **Agree** แล้ว **Confirm** — ขั้นตอนนี้จะสร้าง Messaging API channel ให้อัตโนมัติ (แก้ Provider ภายหลังไม่ได้ ให้เลือกให้ดี)
5. หลังเปิดใช้งานแล้ว ไปที่ https://developers.line.biz/console/ ล็อกอินด้วยบัญชีเดียวกับที่ใช้ใน Official Account Manager
   - จะเจอ **Provider** ที่เลือกไว้ พร้อม channel ประเภท Messaging API ที่ถูกสร้างขึ้นให้อัตโนมัติ (ไม่ต้องกด Create channel เอง)
6. เข้า channel นั้น แล้วทำตามนี้ในแท็บ **Messaging API**:
   - เลื่อนหา **Channel access token** → กด Issue เพื่อสร้างโทเคน → คัดลอกเก็บไว้ (ใช้เป็น `LINE_CHANNEL_ACCESS_TOKEN`)
   - ไปแท็บ **Basic settings** หา **Channel secret** → คัดลอกเก็บไว้ (ใช้เป็น `LINE_CHANNEL_SECRET`)
   - เปิด **Use webhook** เป็น ON
   - ในหัวข้อ **Allow bot to join group chats** ให้เปิดเป็น ON (สำคัญ — ถ้าไม่เปิด จะดึงบอทเข้ากลุ่มไม่ได้)
7. กลับไปที่ **LINE Official Account Manager** → Settings → Response settings → ปิด **Chat**, **Greeting message**, **Auto-response messages** ทั้งหมด (กันชนกับบอทของเรา) และเช็คว่า **Webhooks** เปิดอยู่

> เก็บ 2 ค่านี้ไว้ก่อน: `LINE_CHANNEL_ACCESS_TOKEN` และ `LINE_CHANNEL_SECRET`
> ยังไม่ต้องใส่ Webhook URL ตอนนี้ — จะกลับมาใส่หลัง deploy เสร็จ (ขั้นตอนที่ 4)

## ขั้นตอนที่ 2: เลือก AI สำหรับคำสั่ง `ถาม`

ระบบข่าวไม่ใช้ AI และจัดรูปแบบด้วย Python เท่านั้น ส่วนคำสั่ง `ถาม` รองรับ 4 โหมดผ่าน `AI_PROVIDER`:

| โหมด | ค่าใช้จ่าย | คุณภาพข้อความ | ต้องมี |
|---|---|---|---|
| `none` | ฟรี | ปิดคำสั่งถาม | ไม่ต้องมีอะไรเพิ่ม |
| `local` | ขึ้นกับเครื่อง | ถามตอบด้วย AI ในเครื่อง | เครื่องรัน AI + tunnel |
| `gemini` (ค่าเริ่มต้น) | ตามโควตา Google | ถามตอบทั่วไป | `GEMINI_API_KEY` |
| `anthropic` | ตามค่าบริการ Anthropic | ถามตอบทั่วไป | `ANTHROPIC_API_KEY` |

**แนะนำ:** เริ่มจาก `gemini` สำหรับคำสั่ง `ถาม` และใช้ `none` เมื่อต้องการปิด AI ชั่วคราว

ถ้าจะใช้โหมด `gemini`: สมัครคีย์ฟรีได้ที่ https://aistudio.google.com/apikey (ล็อกอินด้วยบัญชี Google ธรรมดา ไม่ต้องผูกบัตรเครดิต) แล้วคัดลอกคีย์มาใส่ `GEMINI_API_KEY`

ค่าเริ่มต้นของ `GEMINI_MODEL` คือ `gemini-3.6-flash`

> หมายเหตุ: การเปลี่ยนโหมดมีผลเฉพาะคำสั่ง `ถาม` และไม่มีผลต่อระบบข่าว

### ถ้าจะใช้โหมด `local` (ต่อกับ AI ในเครื่องตัวเอง เช่น Ollama)

บอทรันอยู่บน Render (คลาวด์) ส่วน Ollama รันอยู่บนเครื่องคุณเอง ทั้งสองฝั่งจึงคุยกันตรง ๆ ไม่ได้
ต้องเปิด **tunnel** ให้ Ollama ของคุณมี URL ที่เข้าถึงได้จากอินเทอร์เน็ตก่อน วิธีที่ง่ายที่สุดคือใช้ **ngrok**:

1. เข้า https://ngrok.com สมัครบัญชีฟรี แล้วติดตั้งโปรแกรมตามคู่มือของเว็บ (มีให้ทั้ง Windows/Mac/Linux)
2. ล็อกอิน ngrok ในเครื่อง ด้วยคำสั่ง (คัดลอก authtoken จากหน้า dashboard ของ ngrok มาใส่):
   ```
   ngrok config add-authtoken <YOUR_AUTHTOKEN>
   ```
3. ไปที่ Dashboard ของ ngrok > **Cloud Edge > Domains** → กด **Create Domain** จะได้โดเมนฟรีถาวรประมาณ
   `your-name.ngrok-free.app` (ใช้ได้ฟรี 1 โดเมนต่อบัญชี ไม่เปลี่ยนไปเรื่อย ๆ เหมือน URL แบบสุ่ม)
4. เช็คว่า Ollama กำลังรันอยู่ที่พอร์ต 11434 ตามปกติ (ค่าเริ่มต้นของ Ollama)
5. เปิด tunnel ด้วยคำสั่ง (แทน `your-name.ngrok-free.app` ด้วยโดเมนที่ได้จากข้อ 3):
   ```
   ngrok http --url=your-name.ngrok-free.app 11434
   ```
   ปล่อยหน้าต่างนี้เปิดค้างไว้ตลอดเวลาที่อยากใช้คำสั่ง `ถาม` ผ่าน AI local
6. ตั้งค่าใน Render > Environment:
   - `AI_PROVIDER` = `local`
   - `LOCAL_AI_BASE_URL` = `https://your-name.ngrok-free.app/v1` (อย่าลืม `/v1` ต่อท้าย)
   - `LOCAL_AI_MODEL` = `gemma-4-31b-it` (หรือชื่อโมเดลอื่นที่ pull ไว้ใน Ollama)
7. กด Save Changes รอ redeploy แล้วทดสอบทักบอทดูได้เลย

> ข้อควรรู้: เครื่องที่รัน Ollama + ngrok ต้องเปิดอยู่ตลอดเวลาที่ต้องการใช้คำสั่ง `ถาม` ผ่าน local AI

## ขั้นตอนที่ 3: เชื่อมต่อฐานข้อมูลผู้ติดต่อหลัก

ใช้ PostgreSQL ฐานหลักเพียงฐานเดียว โดยตาราง `organizations` และ `contacts` ตรงกับ Prisma models
`Organization` และ `Contact` ที่ใช้ `Int @id @default(autoincrement())` ไม่มีการเชื่อมต่อหรือสำรองไปฐาน secondary

### 2. รันสคริปต์สร้างตาราง

ถ้าตารางยังไม่มี ให้รัน `schema.sql` กับฐานหลักหนึ่งครั้ง หาก Prisma migration สร้างตารางไว้แล้ว ไม่ต้องรันซ้ำ:

```bash
psql "$DATABASE_URL" -f schema.sql
```

หรือวางเนื้อหา `schema.sql` ใน SQL editor ของผู้ให้บริการแล้วรันกับฐานหลักหนึ่งครั้ง

### 3. เอา connection string มาใส่ในบอท

นำ connection string ของฐานหลักมาใส่ใน `DATABASE_URL`

### 4. ตั้งค่าสิทธิ์แอดมิน (แนะนำอย่างยิ่ง)

คำสั่งเพิ่มข้อมูล/ดึงข้อมูลทั้งหมด/ตรวจฐานข้อมูล เป็นคำสั่งที่มีผลต่อข้อมูลจริง ควรจำกัดให้เฉพาะคนที่ไว้ใจ:

1. ถ้ายังไม่ตั้งค่า `LINE_ADMIN_USER_IDS` ไว้เลย ทุกคนที่คุยกับบอทได้จะใช้คำสั่งแอดมินได้หมด (เปิดไว้ก่อนกันใช้งานไม่ได้)
2. หา LINE user id ของตัวเอง: ทักบอทด้วยข้อความอะไรก็ได้ครั้งหนึ่ง แล้วเข้า Render > Logs — ถ้ายังหา user id จาก log ไม่เจอ ให้พิมพ์คุยกับบอทคำสั่งแอดมินอันไหนก็ได้ (เช่น `ตรวจฐานข้อมูล`) แล้วดูใน log ตอนนั้นจะมี error หรือ debug แสดง user id ออกมา (หรือจะเพิ่ม `print(user_id)` ชั่วคราวในโค้ดก็ได้)
3. เอา user id ที่ได้ (ขึ้นต้นด้วย `U` ตามด้วยตัวอักษร/ตัวเลข 32 ตัว) ไปใส่ใน `LINE_ADMIN_USER_IDS` ที่ Render > Environment คั่นด้วย comma ถ้ามีหลายคน เช่น `Uabc123...,Udef456...`

## ขั้นตอนที่ 4: เตรียม Anthropic API Key (ข้ามได้ถ้าไม่ใช้โหมด anthropic)

1. เข้า https://console.anthropic.com
2. สร้าง API key แล้วคัดลอกเก็บไว้ (ใช้เป็น `ANTHROPIC_API_KEY`)
3. เช็คเครดิตที่ Plans & Billing ว่ามีวงเงินเหลือ (บัญชีใหม่ได้ทดลองฟรี ~$5 ครั้งเดียว)

## ขั้นตอนที่ 5: Deploy ขึ้น Render.com (ฟรี)

1. อัปโหลดโค้ดโปรเจกต์นี้ขึ้น GitHub repo ของคุณ (สร้าง repo ใหม่ แล้ว push โฟลเดอร์นี้ทั้งหมด)
2. เข้า https://render.com → สมัคร/ล็อกอิน (เชื่อมกับ GitHub ได้เลย)
3. กด **New +** → **Web Service** → เลือก repo ที่เพิ่ง push ไป
   - Render จะอ่านไฟล์ `render.yaml` ให้อัตโนมัติ (Runtime: Python, Build/Start command ตั้งไว้แล้ว)
   - เลือก plan **Free**
4. ในหน้า **Environment**, ใส่ตัวแปรตามนี้ (ค่าที่เก็บไว้จากขั้นตอนที่ 1-4):
   - `LINE_CHANNEL_ACCESS_TOKEN`
   - `LINE_CHANNEL_SECRET`
   - `DATABASE_URL` (connection string ของฐานข้อมูลหลักจากขั้นตอนที่ 3)
   - `LINE_ADMIN_USER_IDS` (ใส่ LINE user id ของแอดมิน คั่นด้วย comma — จะใส่ทีหลังหลังจากหา user id ตัวเองเจอก็ได้)
   - `AI_PROVIDER` = `gemini` (ใช้กับคำสั่ง `ถาม` เท่านั้น)
   - `LOCAL_AI_BASE_URL`, `LOCAL_AI_MODEL` (ใส่เมื่อ `AI_PROVIDER=local`)
   - `GEMINI_API_KEY` (ใส่เมื่อ `AI_PROVIDER=gemini`)
   - `ANTHROPIC_API_KEY` (ใส่เมื่อ `AI_PROVIDER=anthropic`)
   - `DAILY_DIGEST_HOUR` = 8 (ปรับเวลาที่อยากให้ส่งสรุปข่าวประจำวันได้)
5. กด **Create Web Service** แล้วรอ build เสร็จ (สัก 2-3 นาที)
6. เมื่อ deploy สำเร็จ จะได้ URL ประมาณ `https://line-news-bot-xxxx.onrender.com`

### กลับไปตั้งค่า Webhook URL ที่ LINE

1. กลับไปที่ LINE Developers Console > channel ของคุณ > แท็บ **Messaging API**
2. ใส่ **Webhook URL** เป็น `https://<โดเมนของคุณ>.onrender.com/webhook`
3. กด **Verify** — ควรขึ้นสำเร็จ (สีเขียว)

### แก้ปัญหา Free tier "หลับ" (สำคัญ!)

Render free tier จะพักเซิร์ฟเวอร์ถ้าไม่มีคนเรียกใช้ ~15 นาที ทำให้ข้อความแรกที่ทักมาอาจตอบช้า/ไม่ทัน
วิธีแก้ฟรี ๆ: ใช้ https://uptimerobot.com (สมัครฟรี) ตั้ง monitor แบบ HTTP(s) ให้ ping URL หลักของคุณ
(เช่น `https://line-news-bot-xxxx.onrender.com/`) ทุก 5 นาที เซิร์ฟเวอร์จะไม่หลับและตอบเร็วขึ้นมาก

## ขั้นตอนที่ 6: เพิ่มบอทเป็นเพื่อนและดึงเข้ากลุ่ม

1. ในหน้า Messaging API ของ channel จะมี **QR code** ให้สแกนเพิ่มเพื่อน — ลองทักคุยดูก่อน
2. เมื่อเพิ่มเพื่อนแล้ว เปิดกลุ่มไลน์ที่ต้องการ → เมนูตั้งค่ากลุ่ม → เชิญ → หาชื่อบอทของคุณ → เพิ่มเข้ากลุ่มได้เลย
   (ถ้าหาไม่เจอ ตรวจสอบว่าเปิด "Allow bot to join group chats" ไว้แล้วในขั้นตอนที่ 1)

## วิธีสลับ AI สำหรับคำสั่ง `ถาม`

**วิธีที่เร็วที่สุด — สั่งผ่านแชทได้เลย ไม่ต้องเข้า Render:**

พิมพ์ `โหมด gemini` (หรือ `none` / `local` / `anthropic`) คุยกับบอทตรง ๆ ได้เลย มีผลทันที ไม่ต้อง redeploy
ค่าจะบันทึกใน `storage.json` และมีผลเฉพาะ AI ถามตอบ ต้องตั้ง API key ของ provider นั้นใน Render ด้วย

**วิธีเดิม — ผ่าน Render Environment (ใช้ตั้งค่าเริ่มต้นตอน deploy ครั้งแรก):**

1. ไปที่ Render > service ของคุณ > เมนู **Environment**
2. แก้ค่า `AI_PROVIDER` เป็น `gemini` (หรือ `anthropic`)
3. ถ้าเปลี่ยนเป็น `gemini` ให้เพิ่ม/แก้ `GEMINI_API_KEY` ด้วย
4. กด **Save Changes** — Render จะ redeploy ให้อัตโนมัติ ใช้เวลาสัก 1-2 นาที

> ค่าที่ตั้งผ่านคำสั่งแชทจะ**ทับ**ค่าจาก Render Environment เสมอ ถ้าเคยสั่ง `โหมด xxx` ไว้แล้วอยากกลับไปใช้ค่าจาก Render ให้สั่ง `โหมด none` (หรือโหมดที่ตั้งไว้ใน Render) ผ่านแชทอีกที

## คำสั่งที่ใช้ได้ในแชท/กลุ่ม

| คำสั่ง | ความหมาย |
|---|---|
| `ข่าว` | ดูข่าวเด่นตอนนี้ |
| `หา <คำค้น>` | ค้นข่าวเรื่องนั้นตอนนี้ เช่น `หา ราคาน้ำมัน` |
| `หุ้น <สัญลักษณ์>` | ราคาหุ้นล่าสุด เช่น `หุ้น AAPL` หรือ `หุ้น PTT.BK` |
| `ติดต่อ <ชื่อ/เบอร์/อีเมล/หน่วยงาน/ตัวย่อ>` | ค้นข้อมูลติดต่อ ถ้าตรงชื่อหน่วยงานจะโชว์คนทั้งหน่วยงานเลย พิมพ์ผิดเล็กน้อยก็ยังหาเจอ (ระบบจะเดาคำใกล้เคียงให้พร้อมถาม "เข้าใจว่าคุณหมายถึง...") |
| `ติดต่อฉุกเฉิน` | ดูรายชื่อผู้ติดต่อฉุกเฉินทั้งหมด (คนที่เปิด 24 ชม. ขึ้นก่อน) |
| `ติดตาม <หัวข้อ/สัญลักษณ์หุ้น>` | เพิ่มรายการที่จะรายงานให้ทุกวันอัตโนมัติ |
| `เลิกติดตาม <หัวข้อ>` | เอาออกจากรายการติดตาม |
| `รายการติดตาม` | ดูสิ่งที่ติดตามอยู่ |
| `เปิดข่าวประจำวัน` / `ปิดข่าวประจำวัน` | เปิด-ปิดสรุปข่าวรายวัน |
| `ถาม <คำถาม>` | ถาม AI ทั่วไป แยกจากระบบข่าว |
| `โหมด` | ดู AI provider สำหรับคำสั่ง `ถาม` |
| `โหมด <none/local/gemini/anthropic>` | เลือกหรือปิด AI สำหรับคำสั่ง `ถาม` |
| `ช่วยเหลือ` | แสดงเมนูคำสั่ง |

**คำสั่งแอดมิน** (จำกัดตาม `LINE_ADMIN_USER_IDS` — ดูขั้นตอนที่ 3):

| คำสั่ง | ความหมาย |
|---|---|
| `เพิ่มติดต่อ` (พิมพ์เฉย ๆ) | แสดงฟอร์แมตตัวอย่างสำหรับเพิ่มผู้ติดต่อ |
| `เพิ่มติดต่อ` + รายละเอียดหลายบรรทัด | เพิ่มผู้ติดต่อใหม่ลงฐานหลัก (ดูตัวอย่างด้านล่าง) |
| `ข้อมูลทั้งหมด` | ดึงข้อมูลผู้ติดต่อทั้งหมดในฐาน **main** มาแสดง (จัดกลุ่มตามหน่วยงาน) |
| `ตรวจฐานข้อมูล` | ตรวจการเชื่อมต่อและจำนวนหน่วยงาน/ผู้ติดต่อในฐานหลัก |

ตัวอย่างการเพิ่มผู้ติดต่อ (พิมพ์เป็นข้อความเดียว ขึ้นบรรทัดใหม่ด้วย Shift+Enter):

```
เพิ่มติดต่อ
ชื่อ: นายเอ
หน่วยงาน: กรมป่าไม้
ตัวย่อหน่วยงาน: RFD
ตำแหน่ง: หัวหน้าฝ่าย
เบอร์: 0812345678
อีเมล: a@example.com
ไลน์: nai_a
ประเภท: ทั่วไป
บทบาท: หลัก
24ชม: ไม่
หมายเหตุ: -
```

บังคับแค่ `ชื่อ` กับ `หน่วยงาน` เท่านั้น ฟิลด์อื่นเว้นว่างหรือใส่ `-` ได้ ถ้าหน่วยงานที่พิมพ์ยังไม่มีในระบบ บอทจะสร้างหน่วยงานใหม่ให้อัตโนมัติ ตัวย่อจะถูกแปลงเป็นตัวพิมพ์ใหญ่และต้องไม่ซ้ำกับหน่วยงานอื่น

> **ในกลุ่ม/ห้องแชทหลายคน ต้องพิมพ์คำนำหน้าก่อนทุกครั้งถึงจะตอบ** — ค่าเริ่มต้นคือ `บอท`, `bot`, หรือ `!` (ตั้งค่าเองได้ที่ `GROUP_TRIGGER_KEYWORDS`) เช่น `บอท ข่าว` หรือ `!ข่าว` กันบอทตอบทุกข้อความในกลุ่มโดยไม่จำเป็น ส่วนแชทส่วนตัว 1:1 พิมพ์คำสั่งตรง ๆ ได้เลยไม่ต้องมีคำนำหน้า
>
> เดิมตั้งใจให้ใช้การแท็ก `@ชื่อบอท` แบบ LINE mention จริง แต่บัญชี LINE OA ที่ยังไม่ verified มักไม่ถูกดึงเข้าลิสต์ให้เลือกตอนพิมพ์ `@` ในกลุ่ม ทำให้แท็กไม่ได้ในทางปฏิบัติ — บอทเลยรองรับทั้งสองแบบ ถ้าบัญชี verified แล้วและแท็กได้จริง ก็ใช้การแท็กแทนคำนำหน้าได้เหมือนกัน

พิมพ์ข้อความอื่นที่ไม่ตรงคำสั่งไหนเลย บอทจะค้นข่าวเรื่องนั้นให้อัตโนมัติ (ใช้เป็นการค้นหาทั่วไปก็ได้)

## รันทดสอบในเครื่องตัวเอง (ถ้าอยากลองก่อน deploy จริง)

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # แล้วแก้ค่าจริงในไฟล์ .env
uvicorn app.main:app --reload --port 8000
```

การทดสอบ webhook จริงจากเครื่องตัวเองต้องเปิด URL ออกสู่อินเทอร์เน็ตชั่วคราวด้วยเครื่องมือ เช่น `ngrok http 8000`
แล้วเอา URL ที่ได้ (`https://xxxx.ngrok-free.app/webhook`) ไปใส่ใน LINE Webhook URL ชั่วคราวระหว่างทดสอบ

## โครงสร้างโปรเจกต์

```
line-news-bot/
├── app/
│   ├── main.py        # FastAPI app + webhook + คำสั่งต่าง ๆ
│   ├── db.py          # คิวรี/เขียนข้อมูลผู้ติดต่อใน PostgreSQL ฐานหลัก
│   ├── news.py        # ค้นข่าวแบบไม่ใช้ AI + ราคาหุ้น (yfinance)
│   ├── line_client.py # ส่งข้อความกลับ/push เข้า LINE
│   ├── scheduler.py   # งานสรุปข่าวประจำวันอัตโนมัติ
│   └── storage.py     # เก็บรายชื่อแชท/กลุ่ม หัวข้อติดตาม และ AI provider (ไฟล์ JSON)
├── data/               # ที่เก็บไฟล์ storage.json (สร้างอัตโนมัติตอนรัน)
├── schema.sql          # สคริปต์สร้างตาราง organizations/contacts สำหรับฐานหลัก
├── requirements.txt
├── render.yaml         # ตั้งค่า deploy อัตโนมัติบน Render
├── Procfile
└── .env.example
```

## ข้อจำกัดที่ควรรู้

- ที่เก็บข้อมูลเป็นไฟล์ JSON ธรรมดา เหมาะกับใช้งานส่วนตัว/ทีมเล็ก ถ้ากลุ่ม/ผู้ใช้เยอะมาก ควรย้ายไปใช้ฐานข้อมูลจริง (เช่น PostgreSQL) แทน
- Render free tier ไฟล์ที่เขียนลงดิสก์ (เช่น `data/storage.json`) จะ**หายเมื่อ redeploy** เพราะ free tier ไม่มี persistent disk — ถ้าอยากให้ข้อมูลติดตามอยู่ถาวร ต้องอัปเกรดแผนที่มี persistent disk หรือย้ายไปเก็บใน DB ภายนอก (บอกได้ ช่วยต่อให้ได้)
- ราคาหุ้นจาก yfinance เป็นข้อมูลไม่เป็นทางการ อาจดีเลย์เล็กน้อย ไม่ควรใช้ตัดสินใจซื้อขายจริงแบบเรียลไทม์
- ระบบผู้ติดต่อใช้ฐานหลักเพียงฐานเดียว หากฐานนี้ไม่พร้อมใช้งาน ContactsService จะแจ้งข้อผิดพลาดเฉพาะระบบ และ Service อื่นยังทำงานได้
- ถ้ายังไม่ตั้งค่า `LINE_ADMIN_USER_IDS` คำสั่งแอดมิน (เพิ่ม/ดึงข้อมูลทั้งหมด/ตรวจฐานข้อมูล) จะเปิดให้ทุกคนที่คุยกับบอทใช้ได้ ควรตั้งค่าจำกัดสิทธิ์โดยเร็วที่สุดหลัง deploy (ดูขั้นตอนที่ 3)
